# Plebz

Plebz is a modified version of [Plezy](https://github.com/edde746/plezy),
changed from the original since 2026. It is not affiliated with the Plezy
project; please do not report Plebz issues there.

Licensed under the [GNU General Public License v3.0](LICENSE). The APKs are on
the [Releases](../../releases) page; this repository holds the source they are
built from, and `native/` describes how the player libraries are built.
